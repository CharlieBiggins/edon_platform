# Security and privacy boundary

- Local ActionNet remains tenant isolated.
- Protected local records cannot be promoted.
- Raw payloads, tenant IDs, local experience IDs, direct identifiers,
  credentials, and execution-authority fields are rejected from global
  abstractions.
- Rights, privacy, source review, overlap, and protected-evaluation references
  are content hashed.
- A global release revalidates local eligibility before freezing.
- Memory and releases cannot authorize a gradient update.
- C1 registration rejects online updates and institution-specific weight
  requirements.
- Model dispositions have no operational effect and no binding authority.

These deterministic checks do not replace contractual rights review,
de-identification testing, privacy engineering, DLP, an external security audit,
or customer authorization.
