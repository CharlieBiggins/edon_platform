# Cerebrum System

Status: `INTERNAL_REFERENCE_ARCHITECTURE_NOT_PRODUCTION_AUTHORIZED`

This package is a bounded predecessor component within the unified
`product/cerebrum-platform/` target. Its current implementation status is
preserved; it is not the complete Control Plane or Reasoning Runtime.

Cerebrum is EDON's institutional-intelligence system. C1 is its learned-model
layer. Deterministic state, optimization validation, provenance, ActionNet
qualification, and Kernel authority remain separate components rather than
being hidden inside model weights.

The executable reference upgrade provides separated state projection,
append-only cross-component provenance, a C1 compatibility adapter, and a
non-binding Cerebrum System cycle. It does not provide a trained C1 model,
production connectors, validated causal inference, or autonomous authority.
