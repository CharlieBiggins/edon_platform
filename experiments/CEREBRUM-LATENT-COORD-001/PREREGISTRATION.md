# CEREBRUM-LATENT-COORD-001 preregistration shell

Protocol identity: `CEREBRUM-LATENT-COORD-001-v1.0.0`  
Reserved: 2026-08-30

## Question

Under matched information, tools, action vocabulary, time, and compute, can a
frozen Cerebrum candidate detect, attribute, reconstruct, predict, and safely
route latent state-mediated multi-agent coordination on unseen synthetic
institutions better than message-only, transparent full-state, and unmodified
base-model baselines?

## Conditions

- `message_only_graph`: communications and explicit handoffs only;
- `full_state_rules`: transparent non-learned graph/rule baseline;
- `base_model_full_state`: unmodified base model with the same state projection;
- `cerebrum_full_state`: frozen Cerebrum candidate.

No condition receives future events or a different tool result. Candidate model
and runtime identities remain blank until frozen.

## Reserved protected instrument

The independently custodied instrument contains 480 cases, 96 for each primary
task:

- detection;
- participant/objective attribution;
- causal-path reconstruction;
- downstream forecasting; and
- governance recommendation.

The cases form 240 controlled pairs:

- 120 message-equivalent, state-pivotal pairs;
- 60 state-equivalent, message-pivotal pairs; and
- 60 representation-invariance pairs.

Eight coordination modes receive 60 cases each: direct message, shared queue,
shared artifact, resource mediated, database mutation, configuration mediated,
multihop mixed, and no coordination.

## Information and causal controls

- `available_to_controller_at` must not exceed the case decision time;
- causal labels come from intervention-defined generator structure, not lexical
  descriptions;
- common-shock, shared-clock, shared-resource, and high-activity confounders
  appear as hard negatives;
- identical message traces occur across pivotal state interventions;
- entity names, domains, topologies, renderers, event times, and causal depths
  are disjoint from candidate development material;
- protected generator, oracle, labels, and scorer remain outside the candidate
  runtime.

## Confirmatory disposition

A pass requires two frozen Cerebrum seeds to pass every absolute gate and the
registered comparisons. The only permitted positive language is:

“Across the registered protected synthetic instrument, both frozen Cerebrum
candidates detected and reconstructed bounded state-mediated institutional
coordination better than the registered baselines while producing zero unsafe
authorizations.”

This does not establish real-institution causal validity, universal collective-
behavior detection, production safety, autonomous intervention, or IGI.
