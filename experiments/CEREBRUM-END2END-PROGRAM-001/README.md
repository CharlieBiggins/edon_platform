# CEREBRUM-END2END-PROGRAM-001

Program-001 starts a fresh QLoRA adapter from the frozen Qwen base model. It
does not continue the DEV-017 adapter. Training uses 1,024 fresh trajectories
twice and teaches the model to emit constrained executable temporal programs
from the DEV-020 validated `FAMILIAR_AUGMENTED` interface.

Before training, the unadapted base is frozen as step 0 on development.
Selection compares checkpoints 64 and 128 against those same cases and requires
every absolute gate plus preregistered paired improvement. Confirmation remains
sealed unless one checkpoint qualifies; after opening, base and trained models
are both evaluated on the same 256 cases. The absolute gates cover syntax,
event order, partition, executed state, certificate, decision, and safety.
Every prediction is re-executed through two independent transition engines. The
deterministic envelope accepts only programs whose claims agree with execution;
rejected programs abstain.

The actual DEV-020 Modal result must first be frozen with
`CEREBRUM-DEV-020-INTERFACE-CALIBRATION/finalize_result.py`. Then run
`preflight.py` and `run_program.py` in the registered GPU runtime.

A pass is evidence of a paired training effect for one registered seed, limited
to fresh synthetic in-distribution temporal programs. It is not seed-robust
causality, external transfer, production deployment, binding authority, or IGI.
