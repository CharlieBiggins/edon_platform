# Claims

## Supported

- The data and execution protocol are materialized for a fresh, bounded,
  same-program additive repair campaign.
- The transparent rules ceiling and CPU readiness controls can be checked
  before GPU use.
- RB1 predictions and labels are excluded from training and validation.

## Not supported

- A learned DEV-010 result, a successful repair, independent transfer,
  authorization to materialize Transfer-008, real-institution validity,
  production safety, autonomous authority, or IGI.

## Future disposition

A two-seed pass supports only reproducible project-authored synthetic
held-renderer repair. It would require a newly identified independent-transfer
protocol because Transfer-008 is frozen to the failed RB1 candidates.
