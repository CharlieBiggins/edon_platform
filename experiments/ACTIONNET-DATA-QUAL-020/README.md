# ACTIONNET-DATA-QUAL-020

Fresh synthetic data for validating Cerebrum's input interface before native
temporal-program training. It contains 64 calibration trajectories and 64
disjoint heldout trajectories. Each trajectory has five direct, single-source
representations plus one authenticated immutable-certificate fidelity task.

Run `python run_campaign.py` to reproduce the qualified artifacts. This package
contains no training split and makes no learned-capability, transfer,
production, authority, or IGI claim.
