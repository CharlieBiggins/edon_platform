# Claim boundary

## Supported now

- a frozen, machine-readable minimum internal bounded-IGI capstone has been
  defined;
- its institutions, coverage, conditions, safety invariants, metrics, gates,
  custody sequence, and failure disposition are preregistered;
- shell readiness can be reproduced locally.

## Not supported now

- that RB1 or Transfer-008 has passed;
- that a learned closed-loop C1 candidate exists;
- that the protected capstone instrument exists;
- any capstone performance, transfer, safety, superiority, or IGI result;
- real-institution validity, external replication, production readiness, or
  universal institutional intelligence.

## Conditional post-pass language

Only if both frozen seeds pass every registered gate may EDON describe the
result as an **internal bounded mini-IGI signal within
`CEREBRUM-MINI-IGI-CAPSTONE-001`**. The shorter phrase "IGI proved" remains
prohibited because the capstone is synthetic, finite, internally authored, and
only a subset of the frozen Scope-001 environment universe.
