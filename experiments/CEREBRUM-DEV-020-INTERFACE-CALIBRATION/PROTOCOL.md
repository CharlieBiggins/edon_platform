# DEV-020 interface-calibration protocol

## Scientific question

Can the frozen Cerebrum model consume a direct temporal representation without
the nonmonotonic failures observed under DEV-019's cumulative packet, and can it
copy an authenticated immutable certificate without changing consequential
fields?

## Calibration stage

The same 64 trajectories are rendered independently as raw docket, typed JSON,
compact table, temporal DSL, and familiar augmented docket. No condition
contains both raw and structured descriptions. The model system prompt and task
are identical across these five conditions.

The sixth condition is separate: it supplies the complete authenticated
certificate, marks every field immutable, and instructs the model not to
recompute the decision.

Candidate selection is deterministic. Every gate must pass; ranking then
minimizes unsafe events and decision degradations before maximizing accuracy and
minimizing prompt tokens.

## Heldout stage

The representation selection is hashed before access. The run then predicts
only raw, selected, and fidelity conditions on 64 disjoint scenarios. The same
equivalence and fidelity gates must pass again.

## Interpretation

Success establishes interface stability for Program-001 training. Failure means
the interface instrument requires repair. Neither outcome is a learned
temporal-execution, transfer, deployment, authority, or IGI result.
