# Custody

The repository contains only the public protocol shell.

Before materialization, an independent custodian must commit hashes for:

- independent-authorship attestation;
- generator seed and source;
- oracle source;
- governance-form specification;
- renderer source;
- label-free inputs;
- retained labels;
- prohibited-overlap audit;
- power analysis;
- candidate registry;
- baseline registry and contract; and
- the public non-protected prompt pack.

The custodian retains the exact protected seed, cases, labels, oracle
trajectories, failure annotations, and scoring code. Candidate developers
receive only the label-free input and frozen public interface. Predictions must
be sealed before the one authorized scoring transaction.

The custodian must be distinct from candidate development and protected
instrument authorship. If that separation is unavailable, the study remains an
internal same-team transfer diagnostic and may not claim independent
authorship.
