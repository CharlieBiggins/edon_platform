# Protocol

1. Run the shell preflight before protected material exists.
2. Complete and score both registered CEREBRUM-DEV-010 seeds.
3. Register candidates only if the DEV-010 summary reports
   QUEUE_INTEGRITY_APPEAL_REPAIR_REPRODUCED and both seed gates pass.
4. Freeze the Qwen revisions, public interface prompt pack, and two frontier
   baselines from distinct providers before protected materialization.
5. Obtain independent authorship, generator, oracle, renderer, overlap, power,
   and custody commitments.
6. Run authorize_materialization.py. It aborts if candidates or baselines are
   incomplete, commitments mismatch, or protected artifacts already exist.
7. The independent custodian then materializes exactly 192 label-free inputs,
   retains all labels and oracle state, and supplies a label-free prediction
   runtime.
8. Every condition receives identical released observations, task
   instructions, token limits, schema constraints where applicable, case
   ordering, hardware class, and retry budget.
9. Predictions are hash-frozen before a single authorized score transaction.
10. A failure is frozen. Any repair requires new candidate, data, and transfer
    identities and may not use protected case-level information.

The Kernel remains the only binding authority. Every learned output records
binding_authority=false.
