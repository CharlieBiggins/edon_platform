# Claims

## Supported now

- An engineering-first Cerebrum program is separated from confirmatory research.
- EDON contains an opt-in local Qwen plus optional LoRA provider boundary.
- Learned outputs pass through the existing typed, non-binding operations
  adapter and immutable shadow supervisor.
- Unavailable or malformed generation fails closed to abstention; output that
  carries authority fields is rejected by the adapter.
- Enabling a learned provider requires explicit model lineage.
- RB1 and Transfer-008 claims and gates remain unchanged.

## Unsupported now

- No Build-001 model has been trained or benchmarked.
- No evidence shows that Build-001 outperforms another model.
- No learned closed-loop institutional operation has been demonstrated.
- Transfer, real-institution validity, production safety, IFM, IGI, autonomous
  authority, or general model superiority is not established.

## Permitted language

“CEREBRUM-BUILD-001 provides an exploratory, non-binding local-model engineering
path behind EDON's deterministic safety boundary.”

It may not be described as an IGI result or as proof that Cerebrum beats other
models until separately frozen evaluations support a narrower statement.
