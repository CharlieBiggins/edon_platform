# EDON institutional-intelligence scope registry

This directory contains frozen definitions of the institutional environment
classes over which EDON may formulate bounded generality claims.

The current scope is [`EDON-IGI-SCOPE-001`](EDON-IGI-SCOPE-001/README.md).
Scopes define claim domains; they are not experimental results. A new scope
version is required whenever the admissible environment class, bounds, tasks,
safety invariants, evaluation distribution, or resource assumptions change.

Latent state-mediated coordination is registered separately in
`CEREBRUM-LATENT-COORD-001`. It is not retroactively added to the frozen
Scope-001 task set; promoting it into a bounded-IGI coverage requirement would
require a new scope version and its own protected evidence.
