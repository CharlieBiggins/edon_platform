# CEREBRUM-AWS-DEPLOYMENT-PROFILE-001

Status: `DRAFT_REFERENCE_DEPLOYMENT_NOT_PRODUCTION_QUALIFIED`

This record registers the September 23, 2026 proposed AWS mapping for
`CEREBRUM-PLATFORM-FOUNDATION-001`. It is a replaceable deployment profile, not
part of Cerebrum's frozen platform doctrine.

The profile proposes managed AWS infrastructure, ECS Fargate for CPU services,
qualified non-Fargate GPU paths, RDS PostgreSQL, S3/Object Lock, EventBridge and
SQS, Step Functions, independently governed deployment, and explicit
credential and receipt boundaries.

It creates no deployed infrastructure, AWS cost commitment, business associate
agreement, compliance status, production qualification, customer authorization,
or permission for consequential writes. Its controlling document is
`docs/deployment/cerebrum-aws-deployment-profile-001.md`.
