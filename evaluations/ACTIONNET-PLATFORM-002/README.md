ACTIONNET-PLATFORM-002 evaluates the active institutional-experience upgrade:
canonical Institutional IR, explicit temporal and epistemic state, executable
mechanism composition, replay-verified counterfactual generation, bounded
human-behavior scenarios, and locally minimized governed abstraction intake.

```bash
PYTHONPATH=src python evaluations/ACTIONNET-PLATFORM-002/run_evaluation.py
```

not establish that the generated worlds represent real institutions, the human
scenarios predict people, counterfactuals are externally valid, transfer
