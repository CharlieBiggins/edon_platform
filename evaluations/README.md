# Evaluations

- `ACTIONNET-PLATFORM-001`: 18-gate governed product workflow.
- `ACTIONNET-PLATFORM-002`: 26-gate canonical IR and active experience construction workflow.
- `EDON-OPS-002`: deterministic institutional operations integration.
- `EDON-FED-001`: hierarchical federation and optimization boundary.
- `EDON-AGENT-GATEWAY-001`: vendor-neutral protocol, custody, tenancy, and
  authority-boundary reference.

Evaluation logic is separated from experiment orchestration so metrics and gates
can be reviewed independently. Frozen experiments pin exact scorer hashes.

`EDON-OPS-002/` is the deterministic governed closed-loop integration gate. It
does not establish a learned or real-institution autonomy claim.

`EDON-FED-001/` is the deterministic hierarchical-coordination gate. It covers
redacted multilevel state projection, cross-scope escalation, tenant isolation,
and a non-binding optimization-provider boundary. It is not a production
federation, learned planner, or real logistics result.

`EDON-AGENT-GATEWAY-001/` tests local MCP/FHIR normalization, connector
enablement, immutable custody, replay protection, tenant isolation,
content-minimized telemetry, and the non-binding execution boundary. It makes
no live vendor-interoperability or production-readiness claim.

`ACTIONNET-PLATFORM-001/` is the governed ActionNet product-workflow gate. It
covers mechanism/composition authoring, procedural worlds, experience custody,
protected separation, independent reviews, overlap, releases, exposure,
coverage, acquisition, interventions, tenant isolation, and audit. Passing is
an internal MVP result and does not authorize production deployment.
