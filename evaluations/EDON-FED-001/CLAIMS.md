# Claims

## Supported

- A typed immutable hierarchy can route cross-scope decisions deterministically.
- Facility state can be projected and aggregated without copying raw records.
- Escalation history remains additive and tenant isolated.
- An external optimization provider can be placed behind a validating,
  non-binding adapter that requires subsequent Kernel authorization.

## Not supported

- Learned hierarchical planning or generalization.
- Global optimality of the reference capacity allocator.
- Production identity, consensus, data residency, or broker integration.
- Real logistics, FedEx, aircraft, vehicle, warehouse, or robot validation.
