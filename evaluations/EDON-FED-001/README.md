# EDON-FED-001

EDON-FED-001 is the bounded internal hierarchical-coordination evaluation. It
exercises a global/domain/region/facility scope tree, redacted world-state
projection, multilevel aggregation, least-common-ancestor escalation, additive
escalation custody, tenant isolation, and a non-binding capacity-allocation
adapter.

Run:

```bash
PYTHONPATH=src python evaluations/EDON-FED-001/run_evaluation.py
```

The result is deterministic reference evidence. It does not establish
production federation, learned global planning, optimal logistics allocation,
distributed consensus, or real-institution performance.
