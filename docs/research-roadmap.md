## Product milestones

1. Preserve `CEREBRUM-PLATFORM-VISION-001` and freeze the additive
   `CEREBRUM-PLATFORM-VISION-002` successor with the Control Graph, delegated
   authority/commitment services, and receipt model, without upgrading any
   implementation or scientific claim.
2. Freeze `CEREBRUM-MATURE-PLATFORM-SPEC-001` with eleven canonical
   specifications, including model routing and mature ActionNet custody, while
   preserving the no-implementation claim boundary.
3. Implement additive v1 contracts for the Event Envelope, multidimensional
   Institutional State Model, IR lifecycle, action lifecycle, release and
   deployment, domain packs, and workflow qualification.
4. Introduce a public `/v1` institutional-task facade while preserving existing
   `/api/*` routes as internal reference interfaces during migration.
5. Build the Control Plane around a replayable Institutional Control Graph and
   service-owned identity/capability, mandate, commitment, reservation,
   receipt, and compensation lifecycles.
6. Implement the Model and Solver Registry, enforceable routing policy,
   purpose-bound grants, invocation receipts, runtime budgets, and fail-closed
   fallback behavior.
7. Separate Kernel authorization from Execution Assurance; require exact
   proposal, authorization, state, connector, and idempotency binding before
   dispatch.
8. Place the Deployment Controller between evaluated releases and the Reasoning
   Runtime with signatures, approval, scope, canaries, monitoring, containment,
   attestation, and rollback.
9. Select and register the First Qualified Operational Workflow using customer,
   evidence, safety, measurability, and reuse criteria rather than assuming a
   permanent first industry.
10. Deliver the workflow through compile, historical replay, live shadow,
   assisted operation, and gated expansion, measuring operational value, human
   burden, decision quality, safety, and deployment reuse.
11. Add the bounded Command Center and embedded decision card after the shared
   state, proposal, authorization, execution, and audit contracts are stable.
12. Preserve institution-local experience custody, rights-bound ActionNet
    promotion, protected evaluation, signed release registration, and controlled
    deployment as separate gates.

Existing provenance, compiler, state, world, operations, Kernel-token, outbox,
ActionNet, federation, and gateway components remain reference foundations for
this sequence. Their existence does not mark any milestone complete.
