# Canonical platform specifications

These specifications refine `CEREBRUM-PLATFORM-VISION-001` into versioned
contracts. They define intended platform behavior and compatibility boundaries;
they do not assert that the complete behavior is implemented or qualified.

1. [Event Envelope](event-envelope.md)
2. [Institutional State Model](institutional-state-model.md)
3. [Institutional IR Lifecycle](institutional-ir-lifecycle.md)
4. [Action Lifecycle](action-lifecycle.md)
5. [Release and Deployment Contract](release-deployment-contract.md)
6. [First Qualified Operational Workflow](first-qualified-operational-workflow.md)

Breaking changes require a new schema version and an explicit migration record.
Existing v1 reference contracts remain valid for their recorded uses.
