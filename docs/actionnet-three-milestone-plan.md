# ActionNet / Cerebrum — proposed execution plan, September 14, 2026

This is an additive working plan, not a rewrite of any frozen experiment or
claim that the old mini-IGI prerequisites have passed.

Central question: can ActionNet training improve a small open-weight model's
institutional reasoning and operational proposals beyond matched alternatives,
and can those gains transfer without target-specific retraining?

## Immediate work

Finish Program005 only if the remaining evaluation is worth its cost. Its
training and two trained-arm evaluations were reported complete; a verified
final parent result has not been supplied to this build. Preserve all outcomes,
including HOLD, raw failures, adapters, identities and scores. Program005 has
NO confirmation stage to unlock, and its success cannot authorize transfer.

The separate `CEREBRUM-ACTIONNET-COMPARISON-001` CPU framework can audit/replay a
complete 005 run, prepare a gated fresh screen, and score bound raw outputs.
It does not train, choose/download a baseline, launch inference or contact anyone.

## Milestone 1 — learning contribution

The controlling deliverable is the implemented, blocked-by-default
[Matched-001 written contract](../experiments/CEREBRUM-ACTIONNET-MATCHED-001/CONTRACT.md).
Its framework now includes fresh shared-scenario construction, exact native and
ActionNet serializers, complete-pair token planning, fresh-base QLoRA dispatch,
bound native prediction, offline scoring, and tests. It is not registered or
GPU-validated. A final Program-005 audit, materialized token plan, base snapshot,
cost caps, gate review, registration and separate paid approval remain blockers.

Preserve Comparison-001 unchanged and optional. Its base, parent, ordinary,
targeted and alternative conditions cost 240 responses on 48 cases. It reuses
005 adapters without training; matched record exposure is not token matching.
Run it only if the unresolved question warrants the cost, otherwise record it
as unexecuted. Skipping it is not passing it or changing its gates.

Matched-001 instead compares fresh ordinary and ActionNet adapters from the same
pinned base. Both see both members of the same counterfactual scenario pool and
receive shared native-program targets. Only ActionNet receives explicit pair,
changed-field, causal-effect and intermediate trajectory supervision. The shared
primary output cannot penalize ordinary training for missing ActionNet-only traces.
Match total processed non-padding training tokens; report exposure, supervised
tokens, steps and actual compute separately. Do not claim FLOP matching.

Train Ordinary A and ActionNet A, then run a 24-case development screen: 48
responses. If supported, freeze the unchanged recipe, register seed B and the
broader instrument/gates before broader A results, and train Ordinary B and
ActionNet B. Evaluate all four frozen models in one locked broader transaction.
The proposed locked qualification is 48 fresh cases per model: 192 responses,
with four planned training runs total.
These counts exclude additional controls and failed development attempts.

Require the registered advantage within each seed pair and all absolute,
safety, retention and usefulness gates. Report SUPPORTED, NOT_SUPPORTED or
INCONCLUSIVE only for valid complete evidence; incomplete/invalid execution is
separate. Sample size is a budget proposal, not an established minimum. Shared
pretrained ancestry must be disclosed. Source exclusion is not universal novelty.
Reference-assisted scoring is not production verification, and model-predicted
state is distinct from executor-computed state.

Scaling curves and component ablations are optional, question-driven investments.
A reproduced current recipe can proceed directly to a separately approved
independent transfer test; scaling is not a prerequisite.

## Milestone 2 — independent transfer

Freeze qualified candidates before protected instrument materialization. Use
separate instrument/candidate/scoring roles, unfamiliar institutional structures
and renderers, executable references, overlap audits, matched tool/information
access, and no target-specific training, prompt repair or threshold changes.
Report both seeds separately. Scope claims to the tested institutions.
Freeze ordinary controls as well if claiming the ActionNet advantage transfers;
candidate success alone does not establish that comparative claim. Report
Gold-IR reasoning separately from performance on actual compiler output.

Transfer008 remains closed to candidate substitution. A successor requires a
new identity, candidate/baseline commitments and independent custody. Planning
can precede qualification; protected data access cannot. Run open-weight
comparisons before paying for frontier comparisons only if measured budgets
justify that order; local inference is not presumed cheaper.

## Milestone 3 — useful closed-loop operation and customer evidence

First develop time-gated observation, goals/plans, constrained allocation,
proposals, Kernel rejection handling, outcome monitoring, recovery, replanning
and safe termination in simulation. A proposed 12-episode feasibility pilot
has multiple model decisions per episode and is not the old 72-episode gate.
Changing counts or interfaces requires a new development version.
Development simulation can proceed in parallel without access to protected tests.
Distinguish model-only simulated proposals, model plus State Engine, the governed
model/engine/Kernel system, and a fully specified deterministic controller. An
executor alone is not a planner baseline. No unsafe model-only commits are needed.

Integration work must validate compiler fidelity, gold-IR reasoning versus
compiled-input performance, evidence quality, authorization boundaries, resource
constraints and measured contribution beyond an engine-only baseline. Do not
debug on the protected evaluation.

Prospective Happy Returns and other partner discovery can begin as a separate
human-authorized activity. Ask about a specific workflow, existing performance,
review burden, data rights and measurable value; represent the system as
experimental. No outreach has been sent and no relationship is assumed.

A shadow pilot requires a willing partner, explicit permissions, restricted
data handling, human review, budget/stop rules and no autonomous consequential
commits. Measure quality, corrections, review time, latency and actual cost.
Distinguish measured workflow benefits from projected savings when proposed
actions were not implemented. A paid pilot is a negotiated possibility, not a
promised research outcome.

## Claim and authority limits

Three successful milestones could support a useful specialist-system result.
They do not retroactively pass Capstone001, establish universal IGI, guarantee
zero population risk, or authorize deployment. The existing frozen roadmap and
negative historical results remain intact. Every new paid stage needs an
explicit question, frozen acceptance rules, spending cap and execution approval.

The stages are mandatory for their respective claims, not a claim that every
study is required for every result: matched comparison for learning contribution,
paired seeds for limited reproducibility, independent institutions for transfer,
interactive qualification for operation over time, and a permissioned workflow
study for customer value. None substitutes for the legacy mini-IGI qualification.
